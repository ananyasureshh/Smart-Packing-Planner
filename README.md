# Smart Packing Planner

## Project Goal

When packing for trips, it can get overwhelming when you have to decide and remember what to pack and how much of it to bring. On top of this, they already have to plan an itinerary and sort out flight details. This can stress one out for something that is supposed to be fun.

Instead of people having to manually create their own checklist for what to pack, the goal is to create a smart planner that creates a checklist of items to pack based on the weather of your destination, how long your trip is, and what activities you are planning on doing. The checklists can be customized by the user and keep track of what is packed and what is not.

## MVP (Version 1.0)

- Ask users how many days their trip will last
- Allow users to select a planned activity, such as swimming, hiking, sightseeing, or formal events
- Generate a packing list based on trip duration and activities
- Display the generated packing list
- Allow users to add custom packing items
- Allow users to mark items as packed
- Display the number of packed and remaining items

## Future Plans (Version 2.0+)

- Allow users to select multiple activities for one trip
- Provide weather-based packing recommendations
- Save packing lists so users can access them later

## Tech Stack

- **Programming Language:** Java
- **Development Environment:** Visual Studio Code
- **Input:** Java Scanner class
- **Data Structures:** ArrayList
- **Core Concepts:** Loops, conditionals, methods, classes, and objects
- **Data Storage:** Java file handling (future feature)
